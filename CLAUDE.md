# JP

## Mode de travail par défaut

Sur ce projet, tout travail de code passe par le skill `step-by-step-guided-coder`
(`.claude/skills/step-by-step-guided-coder/SKILL.md`) : une seule étape à la fois,
code complet fourni, et chaque étape structurée en 6 blocs — où agir, pourquoi,
notions clés, le code/la commande, explication détaillée de la syntaxe, validation.

Ne pas enchaîner les étapes sans validation explicite. Ne jamais livrer un bloc de
code ou une commande sans décortiquer sa syntaxe et ses flags.

La progression est suivie dans `LEARNING-MAP.md` à la racine.

## Langue

Réponses et documentation en français. Le code, les identifiants et les messages de
commit suivent les conventions du dépôt.
